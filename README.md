### About Course

This course is designed to teach us one of the most in demand skills which is **SQL** for interacting with database and analyzing our data. We will be working with **PostgreSQL** which is a system that uses SQL and is one of the most demand verses of SQL.

> [!IMPORTANT]
> While we will be only working with PostgreSQL, the syntax and skills we will be learning throughout this course can be applied to any other database or software that uses SQL like: Amazon Redshift, MySQL, Microsoft SQL Server, ORACLE Database & much more.

Throughout the course, we will be getting :

- Comprehensive Video Lectures
- Coding Challenges
- Assessment Test
- Certificate of Completion
